# Images

Every image here is generated by `scripts/make-readme-images.py` from the kit itself, using the bundled Rocha Coded
style and the made-up founder in `examples/unplug.sample.json`. Drawn in code: no photos, no real people.

| File | What it is |
|---|---|
| `docs/img/hero-y2k.png` | the switchboard in the y2k-blog window at 1600x900, one cord dissolving into light and one plug halfway out, used as the README hero |
| `docs/img/triptych.png` | the sample share card in analog, cyberpunk and y2k-blog, each rendered at 1080x1350 |
| `docs/img/ritual.png` | the ritual page at step 4, analog, 1440x1180 |
| `docs/img/space.png` | the space page, cyberpunk, 1440x1100 |
| `docs/img/step-01.svg` to `step-05.svg` | pixel step badges for "Start here" |
| `docs/img/divider.svg` | a gold pixel hairline between README sections |
| `docs/img/heart.svg` | the pixel heart beside "If it goes wrong" and the guestbook line |
