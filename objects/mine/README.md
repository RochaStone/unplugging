# Your own plug and socket

Draw your own plug and socket, if you like, and the switchboard wears them.

- `plug.svg` or `plug.png`: one plug, drawn upright, prongs pointing up. Square-ish works best.
- `socket.svg` or `socket.png`: one socket, seen straight on. Square works best.

Put them in `objects/mine/` inside the folder where you run the kit (your Cowork folder, or wherever you run Claude Code).
PNG or SVG, under 2 MB each. A see-through background looks best.
A missing file is fine: the drawn plug and socket in this kit stand in.

Your drawings stay on your computer. The build tucks them inside your pages so each page needs nothing else.
